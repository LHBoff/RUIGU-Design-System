# Dashboard Pattern

## Intent

用于展示业务概览、核心指标、趋势和关键数据。

## Language Recognition

### Chinese
- 看板
- Dashboard
- 数据看板
- 工作台
- 首页概览
- 经营分析

### English
- KPI dashboard

## Recommended Structure

```
Dashboard
│
├── Page Header
│
├── KPI / Summary Cards
│
├── Charts
│
├── Important Lists
│
└── Secondary Modules
```

## Component Mapping

常见：
- Card
- Statistic
- Table
- Tag
- Progress
- Tabs

Card 用于模块分组。
不要为了统一视觉而给所有元素都套 Card。
